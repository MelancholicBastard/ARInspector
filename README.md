# AR Инспектор

Кросплатформенный Flutter-прототип помощника инженера по ТЗ КСТ ЭНЕРГО ИНЖИНИРИНГ.

Текущий этап: считывание QR-кодов оборудования. Камера открывается по кнопке,
распознаёт только QR, возвращает исходный текст и останавливается. Результат
можно выделить, скопировать и заменить повторным сканированием. Ссылки из QR
автоматически не открываются. Последний результат хранится до закрытия приложения.

Интерфейс на русском языке, Material 3 в стиле Expressive: крупная типографика,
скруглённые карточки, выразительные кнопки, заданная зелёная палитра и системная
светлая/тёмная тема.

## Запуск

Нужен Flutter с Dart 3.14 или новее.

```sh
flutter pub get
flutter run
```

Сканер mobile_scanner поддерживает Android, iOS, macOS и Web.
Разрешения камеры настроены для Android и Apple-платформ.
Для Web используйте HTTPS или localhost; браузер может загружать библиотеку
распознавания при первом запуске. На Android используется встроенная ML Kit,
поэтому распознавание не требует загрузки модели при первом использовании.
На Linux и Windows сканирование камерой пока недоступно.

## Проверки

```sh
flutter analyze
flutter test
flutter build apk --debug
```

Тесты проверяют QR-поток через подмену платформы камеры, повторные события,
пустые данные, повторное сканирование, отмену, жизненный цикл, отказ в доступе,
копирование и узкий экран с увеличенным шрифтом.

На реальном устройстве проверьте разрешение и отказ в доступе, распознавание
напечатанного QR, фонарик, сворачивание и повторное сканирование.
Сборка iOS/macOS требует macOS с Xcode.

## Навигация и настройки

Три вкладки: «Сканер», «Объекты», «Настройки». Считанный QR доступен во вкладке
объектов, но запись оборудования ещё не загружается. Камера открывается
отдельным маршрутом и освобождается при его закрытии.

Настройки сохраняются локально одним JSON-документом через flutter_secure_storage:
ФИО, должность, логин, пароль и URL сервера. На Android отключён Auto Backup,
для iOS настроен Keychain; macOS использует legacy Keychain без общей группы.
На Web требуется HTTPS или localhost. Сохранение не означает успешный вход
или проверку доступности сервера. Для удаления значений очистите поля и сохраните.

Сервер задаётся как базовый HTTP(S) URL (например, http://192.168.1.10:8000).
Строки подключения к PostgreSQL не используются в клиенте. Будущий API должен
искать equipment по qr_code, возвращать компоненты, параметры, измерения,
диагностику и историю обслуживания, а также авторизовать отправку отчётов.
В текущей схеме engineers не содержит учётных данных: серверу потребуется
связать пользователя с engineer_id. В приложении эта связь пока не имитируется.
